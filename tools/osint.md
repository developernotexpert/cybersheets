## Google dorks

```
site:<URL>                              Search only one site
numrange:<START>-<END>                  Search within a number range
date:<INTEGER>                          Search within past # months
link:<URL>                              Find pages that link to URL
related:<URL>                           Find pages related to URL
intitle:<STRING>                        Find pages with string in title
inurl:<STRING>                          Find pages with string in URL
filetype:<EXT>                          Search for files by type
phonebook:<STRING>                      Find phone book listings
```
