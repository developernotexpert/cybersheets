Contribute to CyberSheets

CyberSheets is open source and community-driven. Every cheatsheet is a Markdown file — adding one is just a pull request.

  1. Fork the repo and copy tools/_TEMPLATE.md to tools/<tool>.md.
  2. Fill the front-matter (only category is required) and write the sheet.
  3. Open a pull request — CI validates it, and once merged it deploys automatically.

The fastest way: open tools/_TEMPLATE.md on GitHub, hit edit (it forks for you), and propose the change.
